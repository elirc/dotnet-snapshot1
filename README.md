# Atlas Global Workforce Snapshot History

This repository is a simulated fullstack teaching artifact for a TypeScript/Node backend and React frontend inspired by enterprise global workforce platforms. Each folder under snapshots is a complete copy of the codebase at that moment in the project, not a diff, so a junior engineer can read the system chronologically and compare adjacent folders to see how production-shaped software emerges step by step.

## How to navigate

Start with snapshots/00-walking-skeleton/NOTES.md, answer its "Predict before you read" prompt, then inspect the files listed in "Where to look". Move forward one snapshot at a time. To study the actual code movement, compare two adjacent snapshot folders in VSCode: select both folders, right-click, and choose Compare Selected.
